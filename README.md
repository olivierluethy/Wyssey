# Wyssey — AI Personality Chat

**Guidance from legendary minds.** Wyssey is a web app where you chat with AI personas of
famous thinkers and historical figures for advice, perspective and conversation — powered
by the OpenAI API.

## Features

- Chat with distinct **AI personalities** in dedicated rooms (`room.php`, `chat.html`)
- **OpenAI-powered** responses (`openai.php`, `api.php`)
- Installable **PWA** (app icons + manifest) with built-in privacy and terms pages

## Tech

PHP · OpenAI API · HTML / CSS / JavaScript

## Setup

Provide your **own** OpenAI API key via environment/config — do not commit real keys.
Then serve the PHP files behind any web server.
